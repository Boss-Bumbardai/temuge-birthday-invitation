# Тэмүгэгийн 1 насны төрсөн өдрийн урилга

Гар утасны дэлгэцэд зориулсан, Монгол хэл дээрх хөдөлгөөнт цахим урилга.

## Файлууд
- `index.html` — урилгын бүтэц, текст
- `style.css` — өнгө, загвар, дугтуй болон лацны хөдөлгөөн
- `script.js` — лац дээр дарахад урилга нээх үйлдэл

## Төрсөн өдрийн мэдээлэл
- Нэр: С. Тэмүгэ
- Огноо: 2026 оны 11-р сарын 6
- Байршил: Дархан хот
- Цаг, дэлгэрэнгүй хаяг: Удахгүй зарлана

## GitHub Pages дээр нийтлэх
Repository → Settings → Pages → Build and deployment хэсэгт `Deploy from a branch` сонгоно. Branch: `main`, folder: `/(root)` сонгоод Save дарна. Сайт нийтлэгдэхэд GitHub Pages URL гарч ирнэ.
